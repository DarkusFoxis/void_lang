# 1. Введение

**Void** — это интерпретируемый язык программирования с простым и понятным синтаксисом. Разработан для обучения основам программирования. Интерпретатор написан на TypeScript.

### Ключевые особенности

- 🎯 **Простой синтаксис** — легко читать и писать
- 🎨 **Стили написания** — настройка внешнего вида кода
- 🔢 **Полная арифметика** — включая возведение в степень
- 📝 **Строгая типизация** — 7 типов данных (включая list, dict, var)
- 🔄 **Управляющие конструкции** — условия, циклы, break, continue
- 📦 **Встроенные функции** — математика, строки, конвертация
- 📚 **Массивы** — списки и словари с полным набором операций
- 🔗 **Ссылки** — работа с ссылками на переменные и элементы массивов
- 📁 **Расширение файлов** — `.void`

### Философия языка

```
"Из пустоты рождается код, из кода рождается смысл."
```

Название **Void** (пустота) символизирует чистый лист, с которого начинается каждая программа.

### Что нового в версии 1.4

- ✅ **@VoidSetting** — настройка интерпретатора (лимит итераций, автовывод типа).
- ✅ **@VoidLibs** — поддержка библиотек.
- ✅ **namespace** — пространства имён для библиотек.
- ✅ **fn** — компактный синтаксис функций с `->` для возврата типа.
- ✅ **var** — динамический тип с выводом типа из значения.
- ✅ **break / continue** — управление потоком в циклах.
- ✅ **Ссылки на элементы массивов** — `&arr[i]`.
- ✅ **Расширенное разыменование** — `*` работает с index access.
- ✅ **void как тип переменной** — неинициализированное значение = null.

# 2. Установка и запуск

### Требования

- Node.js 16+
- npm или yarn

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/DarkusFoxis/void_lang
cd void-lang

# Установить зависимости
npm install

# Собрать проект
npm run build
```

### Запуск программы

```bash
# Через собранную версию
node dist/index.js программа.void

# Через ts-node (без сборки)
npx ts-node src/index.ts программа.void

# Помощь
node dist/index.js --help

# Версия
node dist/index.js --version
```

### Первая программа

Создайте файл `hello.void`:

```
@VoidApp "Hello";
using style "Abyss";

main()
{
    echo("Hello, Void!");
}

@VoidEnd;
```

Запустите:

```bash
node dist/index.js hello.void
```

# 3. Структура программы

Каждая программа на Void имеет строгую структуру:

```
┌─────────────────────────────────────────┐
│  @VoidApp "ИмяПриложения";              │  ← Заголовок (обязательно)
│  @VoidSetting max_iteration = -1;       │  ← Настройки (необязательно)
│  using style "Стиль";                   │  ← Стиль (необязательно)
│                                         │
│  fn функция() { ... }                   │  ← Функции (необязательно)
│                                         │
│  main()                                 │  ← Точка входа (обязательно)
│  {                                      │
│      // Ваш код здесь                   │
│  }                                      │
│                                         │
│  @VoidEnd;                              │  ← Конец программы (обязательно)
│  (всё после игнорируется)               │
└─────────────────────────────────────────┘
```

### 3.1 Заголовок программы — `@VoidApp`

Каждая программа **обязана** начинаться с директивы `@VoidApp`:

```
@VoidApp "НазваниеПриложения";
```

- Имя приложения указывается в **двойных кавычках**
- После имени — **точка с запятой**
- Имя используется для идентификации программы при запуске

**Примеры:**

```
@VoidApp "MyFirstApp";
@VoidApp "Calculator";
@VoidApp "Тестовая программа";
```

### 3.2 Заголовок библиотеки — `@VoidLibs`

Файлы библиотек начинаются с директивы `@VoidLibs`:

```
@VoidLibs "ИмяБиблиотеки";
namespace "пространство_имён";

// Функции библиотеки

@VoidEnd;
```

Подробнее — в разделе [5. Библиотеки](#5-библиотеки-voidlibs).

### 3.3 Настройки — `@VoidSetting`

Необязательная директива для настройки поведения интерпретатора:

```
@VoidSetting max_iteration = -1;
@VoidSetting automatic_type = true;
```

Подробнее — в разделе [4. Настройки интерпретатора](#4-настройки-интерпретатора-voidsetting).

### 3.4 Стиль — `using style`

Необязательная директива, указывающая стиль написания кода:

```
using style "ИмяСтиля";
```

Подробнее о стилях — в разделе [6. Стили написания](#6-стили-написания-using-style).

### 3.5 Функция `main()`

Точка входа — обязательная функция `main()`:

```
main()
{
    // Весь исполняемый код здесь
}
```

- Скобки `()` после `main` обязательны
- Тело функции заключается в фигурные скобки `{ }`
- Выполнение программы начинается с первой инструкции внутри `main()`

### 3.6 Конец программы — `@VoidEnd`

Каждая программа **обязана** заканчиваться директивой:

```
@VoidEnd;
```

**Всё, что написано после `@VoidEnd;`, полностью игнорируется.** Это удобно для:

- Заметок разработчика
- Черновиков кода
- Документации

```
@VoidEnd;

Здесь можно писать что угодно.
Этот текст не будет обработан интерпретатором.
TODO: добавить новые функции
```

# 4. Настройки интерпретатора (@VoidSetting)

Директива `@VoidSetting` позволяет настраивать поведение интерпретатора.

### 4.1 Синтаксис

```
@VoidSetting ключ = значение;
```

| Часть | Описание |
|---|---|
| `@VoidSetting` | Директива настройки |
| `ключ` | Имя настройки |
| `=` | Оператор присваивания |
| `значение` | Строка, число или bool |
| `;` | Конец инструкции |

### 4.2 Доступные настройки

#### `max_iteration` — Лимит итераций циклов

Определяет максимальное количество итераций для `while` и `for` циклов.

```
@VoidSetting max_iteration = -1;
```

| Значение | Описание |
|---|---|
| `1000000` | Стандартный лимит (по умолчанию) |
| `-1` | Бесконечный цикл (без лимита) |
| Любое положительное число | Пользовательский лимит |

**Пример с бесконечным циклом:**

```
@VoidApp "Infinity";
@VoidSetting max_iteration = -1;

main()
{
    for (; ; )
    {
        echo("Бесконечный цикл!");
    }
}

@VoidEnd;
```

#### `automatic_type` — Автоматический вывод типа

Включает автоматический вывод типа переменной из значения инициализатора для типа `var`.

```
@VoidSetting automatic_type = true;
```

**Пример:**

```
@VoidApp "AutoType";
@VoidSetting automatic_type = true;

main()
{
    create:var x = 42;      // Тип: int
    create:var y = "hello"; // Тип: string
    create:var z = 3.14;    // Тип: float
    
    x = "now I'm a string"; // Тип меняется на string
    echo(x);
}

@VoidEnd;
```

### 4.3 Порядок настройки

Настройки применяются **до** выполнения кода. Они должны быть объявлены после `@VoidApp`, но до `main()`:

```
@VoidApp "MyApp";
@VoidSetting max_iteration = -1;
@VoidSetting automatic_type = true;
using style "Abyss";

main()
{
    // Настройки уже применены
}

@VoidEnd;
```

# 5. Библиотеки (@VoidLibs)

Библиотеки позволяют разделять код на переиспользуемые модули.

### 5.1 Создание библиотеки

Файл библиотеки начинается с `@VoidLibs` вместо `@VoidApp` и содержит `namespace`:

```
@VoidLibs "MathLib";
namespace "math";

fn add(int a, int b) -> int {
    return a + b;
}

fn multiply(int a, int b) -> int {
    return a * b;
}

@VoidEnd;
```

### 5.2 Импорт библиотеки

Для подключения библиотеки используйте директиву `@VoidImport`:

```
@VoidApp "MyApp";
@VoidImport "libs/math.void";

main()
{
    create:int result = math::add(1, 2);
    echo(result); // 3
}

@VoidEnd;
```

### 5.3 Вызов функций из библиотеки

Функции вызываются через `::` (двоеточие):

```
namespace::имя_функции(аргументы);
```

**Пример:**

```
create:int sum = math::add(5, 3);
create:int product = math::multiply(4, 7);
```

### 5.4 Структура каталога

```
my_project/
├── libs/
│   └── math.void        # Библиотека
├── main.void             # Основная программа
└── package.json
```

### 5.5 Ограничения библиотек

- Библиотека **не может** содержать `main()`
- Библиотека **не может** содержать `echo()` или `write()` (только функции)
- Библиотека **не выполняется** при запуске — только её функции регистрируются
- Библиотеки могут вызывать друг друга через `@VoidImport`

# 6. Стили написания (using style)

Стили в Void — это **философия и рекомендации по написанию кода**. Стиль задаёт тон и настроение программы. На данный момент стиль является декоративной директивой, но в будущих версиях может влиять на поведение интерпретатора.

### 6.1 Доступные стили

#### 🌑 `"Abyss"` — Бездна

```
using style "Abyss";
```

**Философия:** Минимализм и глубина. Код, рождённый из пустоты.

**Рекомендации:**
- Минимальное количество переменных
- Короткие имена
- Лаконичные конструкции
- Глубокая вложенность допустима

**Пример в стиле Abyss:**

```
@VoidApp "Deep";
using style "Abyss";

main()
{
    create:int x = 42;
    echo(x * x);
}

@VoidEnd;
```

---

#### 🌅 `"Dawn"` — Рассвет

```
using style "Dawn";
```

**Философия:** Ясность и чистота. Каждая строка — как первый луч солнца.

**Рекомендации:**
- Понятные имена переменных
- Обильные комментарии
- Одно действие — одна строка
- Избегать глубокой вложенности

---

#### 🌙 `"Twilight"` — Сумерки

```
using style "Twilight";
```

**Философия:** Баланс между светом и тьмой. Элегантность в каждой строке.

**Рекомендации:**

- Умеренные комментарии
- Группировка логических блоков
- Элегантные решения

**Рекомендации:**

# 7. Комментарии

### 7.1 Однострочные комментарии

Начинаются с `//` и продолжаются до конца строки:

```
// Это комментарий
echo("Hello"); // Комментарий после кода
```

### 7.2 Многострочные комментарии

Заключаются между `#*` и `*#`:

```
#*
    Это многострочный комментарий.
    Он может занимать несколько строк.
    Удобен для описания алгоритмов.
*#
```

### 7.3 Рекомендации по комментариям

```
@VoidApp "CommentDemo";
using style "Dawn";

main()
{
    // ===== Блок инициализации =====
    create:int x = 10;    // Координата X
    create:int y = 20;    // Координата Y

    #*
        Вычисляем расстояние от начала координат
        по формуле: d = sqrt(x² + y²)
    *#
    create:float distance = sqrt(x ** 2 + y ** 2);
    
    echo("Расстояние:", distance);
}

@VoidEnd;
```

# 8. Типы данных

Void поддерживает **7 типов данных**:

### 8.1 `string` — Строка

Текстовые данные, заключённые в двойные или одинарные кавычки.

```
create:string name = "Void Language";
create:string quote = "Он сказал: \"Привет!\"";
```

**Escape-последовательности:**

| Последовательность | Значение |
|---|---|
| `\n` | Новая строка |
| `\t` | Табуляция |
| `\r` | Возврат каретки |
| `\\` | Обратный слэш |
| `\"` | Двойная кавычка |
| `\'` | Одинарная кавычка |

**Конкатенация строк:**

```
create:string first = "Hello";
create:string second = " World";
create:string result = first + second;  // "Hello World"
```

**Конкатенация с другими типами:**

```
create:string msg = "Ответ: " + 42;      // "Ответ: 42"
create:string msg2 = "Пи = " + 3.14;     // "Пи = 3.14"
create:string msg3 = "Флаг: " + true;    // "Флаг: true"
```

**Доступ к символу по индексу:**

```
create:string word = "Hello";
echo(word[0]);    // H
echo(word[-1]);   // o
```

### 8.2 `int` — Целое число

Целые числа без дробной части.

```
create:int age = 25;
create:int negative = -10;
create:int zero = 0;
create:int big = 1000000;
```

**Особенности:**
- При присваивании дробного числа — **округление вниз** (floor)
- Диапазон ограничен JavaScript Number

### 8.3 `float` — Число с плавающей точкой

Числа с дробной частью.

```
create:float pi = 3.14159;
create:float temperature = -15.5;
create:float small = 0.001;
```

**Особенности:**
- Стандартная точность IEEE 754
- Разделитель дробной части — **точка**

### 8.4 `bool` — Логический тип

Значения `true` (истина) или `false` (ложь).

```
create:bool isActive = true;
create:bool hasError = false;
```

**Таблица истинности для приведения:**

| Значение | bool |
|---|---|
| `0` | `false` |
| `0.0` | `false` |
| `""` (пустая строка) | `false` |
| `false` | `false` |
| `null` | `false` |
| `[]` (пустой список) | `false` |
| `{}` (пустой словарь) | `false` |
| Любое другое | `true` |

### 8.5 `list` — Список

Упорядоченная коллекция элементов любого типа. Подробнее — в разделе [11. Массивы](#11-массивы-списки-и-словари).

```
create:list items = [1, 2, "hello", true, 3.14];
```

### 8.6 `dict` — Словарь

Коллекция пар ключ-значение. Подробнее — в разделе [11. Массивы](#11-массивы-списки-и-словари).

```
create:dict user = {"name":"Void", "version":1};
```

### 8.7 `var` — Динамический тип

**Новое в версии 1.4.** Переменная, тип которой определяется из значения инициализатора. Позволяет менять тип при повторном присваивании.

```
create:var x = 42;      // Тип: int
create:var y = "hello"; // Тип: string
create:var z = 3.14;    // Тип: float

x = "now I'm a string"; // Тип меняется на string
```

**Особенности:**
- Тип выводится автоматически из значения
- Может быть неинициализирован: `create:var x;` → тип: null, значение: null
- При присваивании нового значения тип может измениться

### 8.8 `void` — Пустой тип

Переменная типа `void` может быть неинициализирована (значение по умолчанию: `null`). Позволяет менять тип при присваивании.

```
create:void x;           // x = null
create:void y = 42;      // y = 42 (int)
create:void z = "hello"; // z = "hello" (string)
```

### 8.9 `link` — Ссылка

Тип ссылки на переменную или элемент массива. Подробнее — в разделе [16. Ссылки и разыменование](#16-ссылки-и-разыменование).

```
create:int a = 10;
create:link ptr = &a;
```

### 8.10 Сводная таблица типов

| Тип | Ключевое слово | Пример | Описание |
|---|---|---|---|
| Строка | `string` | `"Hello"` | Текстовые данные |
| Целое число | `int` | `42` | Целые числа |
| Дробное число | `float` | `3.14` | Числа с точкой |
| Логический | `bool` | `true` / `false` | Истина / ложь |
| Список | `list` | `[1, 2, 3]` | Упорядоченная коллекция |
| Словарь | `dict` | `{"a":1}` | Пары ключ-значение |
| Динамический | `var` | `42` / `"hello"` | Автовывод типа |
| Пустой | `void` | `null` | Неинициализированная переменная |
| Ссылка | `link` | `&variable` | Ссылка на переменную |

# 9. Переменные

### 9.1 Создание переменных

**Синтаксис:**

```
create:тип имя = значение;
```

| Часть | Описание |
|---|---|
| `create:` | Ключевое слово создания переменной |
| `тип` | Один из: `string`, `int`, `float`, `bool`, `list`, `dict`, `var`, `void`, `link` |
| `имя` | Имя переменной (буквы, цифры, `_`) |
| `=` | Оператор присваивания |
| `значение` | Выражение или литерал |
| `;` | **Точка с запятой в конце** (обязательна!) |

**Примеры:**

```
create:string name = "Void";
create:int count = 0;
create:float ratio = 0.75;
create:bool isReady = true;
create:list items = [1, 2, 3];
create:dict config = {"debug":false, "version":1};
create:var dynamic = 42;
create:void empty;
```

### 9.2 Именование переменных

**Правила:**
- Начинается с **буквы** или `_`
- Содержит **буквы**, **цифры**, `_`
- **Регистрозависимые** (`name` ≠ `Name`)
- Не может совпадать с ключевыми словами

**Допустимые имена:**

```
create:int x = 1;
create:int myVariable = 2;
create:int _private = 3;
create:int player1Score = 100;
create:int MAX_VALUE = 999;
```

**Недопустимые имена:**

```
create:int 1variable = 1;   // Начинается с цифры
create:int my-var = 2;      // Содержит дефис
create:int main = 3;        // Ключевое слово
```

### 9.3 Инициализация выражениями

Переменные можно инициализировать любым выражением:

```
create:int sum = 10 + 20;
create:float area = 3.14 * 5 ** 2;
create:string greeting = "Hello, " + "World!";
create:bool isAdult = 25 >= 18;
create:int sqrtVal = toInt(sqrt(144));
create:list combined = [1, 2] + [3, 4];
```

### 9.4 Изменение переменных

После создания значение можно изменить:

```
create:int x = 10;
echo(x);        // 10

x = x + 5;
echo(x);        // 15

x = x * 2;
echo(x);        // 30
```

> ⚠️ **Важно:** Изменение сохраняет тип. Если переменная `int`, присваиваемое значение будет приведено к `int`.

### 9.5 Область видимости

Переменные имеют **блочную область видимости**:

```
create:int x = 10;

if (true)
{
    create:int y = 20;     // y видна только здесь
    echo(x);               // 10 — x видна из внешнего блока
    echo(y);               // 20
}

echo(x);                   // 10 — OK
// echo(y);                // ОШИБКА — y не определена здесь
```

### 9.6 Ввод данных в переменную

```
create:string name = write("Ваше имя: ");
create:string ageStr = write("Ваш возраст: ");
create:int age = toInt(ageStr);
```

# 10. Функции

### 10.1 Объявление функции — `@VoidFunction`

**Синтаксис:**

```
@VoidFunction возвращаемый_тип имя_функции(тип1 параметр1, тип2 параметр2, ...) 
{
    // Тело функции
    return значение; // Необязательно
}
```

**Пример:**

```
@VoidFunction create:int add(create:int a, create:int b) {
    return a + b;
}

@VoidFunction create:void greet(create:string name) {
    echo("Привет,", name + "!");
}

main()
{
    create:int result = add(5, 3);
    echo(result); // 8
    
    greet("Void"); // Привет, Void!
}
```

### 10.2 Компактный синтаксис — `fn`

**Новое в версии 1.4.** Альтернативный способ объявления функций с указанием возвращаемого типа через `->`:

```
fn имя_функции(тип1 параметр1, тип2 параметр2) -> возвращаемый_тип 
{
    // Тело функции
    return значение;
}
```

**Пример:**

```
fn add(int a, int b) -> int {
    return a + b;
}

fn greet(string name) -> void {
    echo("Привет,", name + "!");
}

fn multiply(int a, int b) -> int {
    return a * b;
}

main()
{
    echo(add(5, 3));       // 8
    greet("Void");         // Привет, Void!
    echo(multiply(4, 7));  // 28
}
```

> ⚠️ **Примечание:** В синтаксисе `fn` типы параметров указываются **без** `create:`.

### 10.3 Возвращаемый тип

Функции могут возвращать значения любого типа:

```
fn getNumber() -> int {
    return 42;
}

fn getString() -> string {
    return "Hello";
}

fn getList() -> list {
    return [1, 2, 3];
}
```

Если функция ничего не возвращает, используйте тип `void`:

```
fn doSomething() -> void {
    echo("Действие выполнено");
    // Не нужен return
}
```

### 10.4 Параметры функций

Параметры передаются по значению:

```
fn double(create:int x) -> int {
    return x * 2;
}

main()
{
    create:int a = 5;
    echo(double(a)); // 10
    echo(a);         // 5 (а не изменилось)
}
```

### 10.5 Рекурсия

Функции могут вызывать сами себя:

```
fn factorial(create:int n) -> int {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

main()
{
    echo(factorial(5));  // 120
    echo(factorial(10)); // 3628800
}
```

### 10.6 return

Оператор `return` завершает выполнение функции и возвращает значение:

```
fn divide(create:int a, create:int b) -> int {
    if (b == 0) {
        echo("Ошибка: деление на ноль!");
        return 0;
    }
    return a / b;
}
```

# 11. Массивы (Списки и Словари)

Void поддерживает два типа коллекций: **списки** (`list`) и **словари** (`dict`). Оба могут хранить элементы любых типов.

---

### 11.1 Списки (`list`)

Список — упорядоченная коллекция элементов с доступом по числовому индексу.

#### Создание списка

```
create:list Variable = [1, 2, true, "New-file"];
```

Элементы могут быть **любого типа**: числа, строки, bool.

```
create:list empty = [];
create:list numbers = [10, 20, 30, 40, 50];
create:list mixed = [1, "hello", true, 3.14];
```

#### Доступ по индексу

```
create:list items = [1, 2, true, "New-file"];

echo(items[0]);     // 1         — первый элемент
echo(items[1]);     // 2         — второй элемент
echo(items[3]);     // New-file  — четвёртый элемент
```

#### Отрицательные индексы

Отрицательные индексы считают с конца списка:

```
create:list items = [1, 2, true, "New-file"];

echo(items[-1]);    // New-file  — последний элемент
echo(items[-2]);    // true      — предпоследний элемент
```

#### Добавление элемента — `add:list`

Добавляет элемент **в конец** списка:

```
create:list items = [1, 2, 3];
items.add:list("Data");
echo(items);    // [1, 2, 3, Data]
```

#### Удаление элемента — `delete:list`

Удаляет элемент **по индексу**:

```
create:list items = [1, 2, 3, 4, 5];
items.delete:list(0);
echo(items);    // [2, 3, 4, 5]

items.delete:list(-1);
echo(items);    // [2, 3, 4]
```

#### Очистка списка — `clear:list`

Удаляет **все элементы** из списка:

```
create:list items = [1, 2, 3];
items.clear:list();
echo(items);    // []
```

#### Конкатенация списков

Оператор `+` объединяет два списка:

```
create:list a = [1, 2, 3];
create:list b = [4, 5, 6];
create:list c = a + b;
echo(c);    // [1, 2, 3, 4, 5, 6]
```

---

### 11.2 Словари (`dict`)

Словарь — коллекция пар **ключ:значение**. Ключи и значения могут быть любого типа.

#### Создание словаря

```
create:dict Variable = {"Data":"key", 1:"Yes"};
```

Ключами могут быть строки, числа, bool:

```
create:dict empty = {};
create:dict user = {"name":"Alice", "age":25, "active":true};
create:dict config = {1:"first", 2:"second", 3:"third"};
```

#### Доступ по ключу

```
create:dict user = {"name":"Alice", "age":25};

echo(user["name"]);    // Alice
echo(user["age"]);     // 25
```

```
create:dict config = {1:"Yes", 2:"No"};

echo(config[1]);       // Yes
echo(config[2]);       // No
```

#### Добавление пары — `add:dict`

Добавляет новую пару ключ:значение. Если ключ уже существует — **обновляет значение**:

```
create:dict data = {"a":1, "b":2};

// Добавление новой пары
data.add:dict("c":3);
echo(data);    // {a:1, b:2, c:3}

// Обновление существующего ключа
data.add:dict("a":100);
echo(data);    // {a:100, b:2, c:3}
```

> ⚠️ **Синтаксис:** `add:dict(ключ:значение)` — ключ и значение разделяются двоеточием `:` внутри скобок.

#### Удаление пары — `delete:dict`

Удаляет пару **по ключу**:

```
create:dict data = {"x":10, "y":20, "z":30};
data.delete:dict("y");
echo(data);    // {x:10, z:30}
```

#### Очистка словаря — `clear:dict`

Удаляет **все пары** из словаря:

```
create:dict data = {"a":1, "b":2};
data.clear:dict();
echo(data);    // {}
```

### 11.3 Сводная таблица методов коллекций

| Метод | Список (`list`) | Словарь (`dict`) |
|---|---|---|
| **Создание** | `create:list V = [1, 2, 3];` | `create:dict D = {"a":1};` |
| **Доступ** | `V[0]`, `V[-1]` | `D["key"]`, `D[1]` |
| **Добавление** | `V.add:list(значение);` | `D.add:dict(ключ:значение);` |
| **Удаление** | `V.delete:list(индекс);` | `D.delete:dict(ключ);` |
| **Очистка** | `V.clear:list();` | `D.clear:dict();` |
| **Длина** | `length(V)` | `length(D)` |
| **Поиск** | `contains(V, значение)` | — |
| **Конкатенация** | `V1 + V2` | — |

# 12. Операторы

### 12.1 Арифметические операторы

| Оператор | Описание | Пример | Результат |
|---|---|---|---|
| `+` | Сложение | `5 + 3` | `8` |
| `-` | Вычитание | `5 - 3` | `2` |
| `*` | Умножение | `5 * 3` | `15` |
| `/` | Деление | `7 / 2` | `3.5` |
| `%` | Остаток от деления | `7 % 3` | `1` |
| `**` | Возведение в степень | `2 ** 10` | `1024` |

### 12.2 Конкатенация строк и списков

Оператор `+` для строк выполняет **конкатенацию**:

```
create:string result = "Hello" + ", " + "World!";
echo(result);  // Hello, World!
```

Оператор `+` для списков выполняет **объединение**:

```
create:list a = [1, 2];
create:list b = [3, 4];
echo(a + b);    // [1, 2, 3, 4]
```

### 12.3 Операторы сравнения

| Оператор | Описание | Пример | Результат |
|---|---|---|---|
| `==` | Равно | `5 == 5` | `true` |
| `!=` | Не равно | `5 != 3` | `true` |
| `<` | Меньше | `3 < 5` | `true` |
| `>` | Больше | `5 > 3` | `true` |
| `<=` | Меньше или равно | `5 <= 5` | `true` |
| `>=` | Больше или равно | `5 >= 3` | `true` |

### 12.4 Логические операторы

| Оператор | Описание | Пример | Результат |
|---|---|---|---|
| `&&` | Логическое И | `true && false` | `false` |
| `\|\|` | Логическое ИЛИ | `true \|\| false` | `true` |
| `!` | Логическое НЕ | `!true` | `false` |

### 12.5 Унарные операторы

| Оператор | Описание | Пример | Результат |
|---|---|---|---|
| `-` | Унарный минус | `-42` | `-42` |
| `!` | Логическое отрицание | `!true` | `false` |
| `&` | Адрес (ссылка) | `&x` | Ссылка на x |
| `*` | Разыменование | `*ptr` | Значение по ссылке |

### 12.6 Операторы инкремента и декремента

**Новое в версии 1.2.** Увеличение/уменьшение значения на 1:

| Оператор | Описание | Пример | Результат |
|---|---|---|---|
| `++` | Инкремент | `x++` | x увеличивается на 1 |
| `--` | Декремент | `x--` | x уменьшается на 1 |

```
create:int x = 5;
x++;        // x = 6
x--;        // x = 5
```

### 12.7 Составные операторы присваивания

**Новое в версии 1.2.** Упрощённая запись арифметических операций:

| Оператор | Эквивалент | Пример | Результат |
|---|---|---|---|
| `+=` | `x = x + y` | `x += 5` | x увеличивается на 5 |
| `-=` | `x = x - y` | `x -= 3` | x уменьшается на 3 |
| `*=` | `x = x * y` | `x *= 2` | x умножается на 2 |
| `/=` | `x = x / y` | `x /= 4` | x делится на 4 |
| `%=` | `x = x % y` | `x %= 3` | x = x % 3 |

```
create:int counter = 0;
counter += 5;   // counter = 5
counter *= 2;   // counter = 10
counter -= 3;   // counter = 7
```

### 12.8 Оператор индексации `[]`

Оператор `[]` используется для доступа к элементам коллекций и строк:

```
create:list items = [10, 20, 30];
echo(items[0]);       // 10
echo(items[-1]);      // 30

create:dict data = {"key":"value"};
echo(data["key"]);    // value

create:string word = "Hello";
echo(word[0]);        // H
echo(word[-1]);       // o
```

### 12.9 Приоритет операторов

От **высшего** к **низшему**:

| Приоритет | Оператор | Ассоциативность |
|---|---|---|
| 1 (высший) | `()`, `[]` | — |
| 2 | `-` (унарный), `!`, `&`, `*` | Правая |
| 3 | `++`, `--` | Правая |
| 4 | `**` | **Правая** |
| 5 | `*`, `/`, `%` | Левая |
| 6 | `+`, `-` | Левая |
| 7 | `<`, `>`, `<=`, `>=` | Левая |
| 8 | `==`, `!=` | Левая |
| 9 | `&&` | Левая |
| 10 (низший) | `\|\|` | Левая |

**Примеры приоритета:**

```
echo(2 + 3 * 4);          // 14  (не 20)
echo((2 + 3) * 4);        // 20
echo(2 ** 3 ** 2);         // 512 (= 2^9, правая ассоциативность)
echo(true || false && false);  // true (&& выше ||)
```

### 12.10 Скобки

Скобки `()` изменяют приоритет вычислений:

```
create:int a = (2 + 3) * (4 - 1);     // 15
create:int b = 2 + 3 * 4 - 1;         // 13
create:float c = (10.0 + 20.0) / 3.0; // 10.0
```

# 13. Ввод и вывод

### 13.1 Вывод — `echo()`

Выводит одно или несколько значений в консоль:

**Синтаксис:**

```
echo(выражение1, выражение2, ...);
```

**Примеры:**

```
// Одно значение
echo("Hello, World!");

// Несколько значений (разделяются пробелом)
echo("Имя:", "Void");
echo("Возраст:", 25);

// Выражения
echo(2 + 2);
echo("Результат:", 10 * 5 + 3);

// Переменные
create:string name = "User";
echo("Привет,", name, "!");

// Коллекции
create:list items = [1, 2, 3];
echo("Список:", items);
```

### 13.2 Ввод — `write()`

Читает данные от пользователя с консоли:

**Синтаксис:**

```
write("подсказка")
```

`write()` — это **выражение**, которое возвращает **строку**.

**Примеры:**

```
// Простой ввод строки
create:string name = write("Ваше имя: ");

// Ввод числа (требуется преобразование)
create:string input = write("Введите число: ");
create:int number = toInt(input);

// Ввод дробного числа
create:float value = toFloat(write("Введите значение: "));
```

> ⚠️ **В веб-плейд round:** `write()` использует `window.prompt()` вместо консоли.

# 14. Условные конструкции

### 14.1 Простое условие — `if`

```
if (условие)
{
    // Код выполняется, если условие истинно
}
```

### 14.2 Условие с альтернативой — `if-else`

```
if (условие)
{
    // Если истина
}
else
{
    // Если ложь
}
```

### 14.3 Цепочка условий — `if-else if-else`

```
if (условие1)
{
    // Блок 1
}
else if (условие2)
{
    // Блок 2
}
else if (условие3)
{
    // Блок 3
}
else
{
    // Блок по умолчанию
}
```

**Пример:**

```
create:int score = 75;

if (score >= 90)
{
    echo("Отлично! (A)");
}
else if (score >= 80)
{
    echo("Хорошо (B)");
}
else if (score >= 70)
{
    echo("Удовлетворительно (C)");
}
else if (score >= 60)
{
    echo("Посредственно (D)");
}
else
{
    echo("Неудовлетворительно (F)");
}
```

### 14.4 Вложенные условия

```
create:int x = 10;
create:int y = 20;

if (x > 0)
{
    if (y > 0)
    {
        echo("Обе координаты положительные");
    }
    else
    {
        echo("x положительный, y отрицательный");
    }
}
else
{
    echo("x отрицательный или ноль");
}
```

# 15. Циклы

### 15.1 Цикл `while`

Выполняет блок кода, **пока условие истинно**:

```
while (условие)
{
    // Тело цикла
}
```

**Пример — сумма чисел:**

```
create:int sum = 0;
create:int n = 1;
while (n <= 100)
{
    sum = sum + n;
    n = n + 1;
}
echo("Сумма 1..100 =", sum);  // 5050
```

### 15.2 Цикл `for`

Компактная запись цикла с инициализацией, условием и обновлением:

```
for (инициализация; условие; обновление)
{
    // Тело цикла
}
```

**Пример:**

```
for (create:int i = 0; i < 10; i = i + 1)
{
    echo(i);
}
```

### 15.3 break и continue

**Новое в версии 1.4.**

#### `break` — выход из цикла

```
create:int i = 0;
while (true)
{
    if (i >= 5) break;
    echo(i);
    i++;
}
// Вывод: 0 1 2 3 4
```

#### `continue` — переход к следующей итерации

```
for (create:int i = 0; i < 10; i++)
{
    if (i % 2 == 0) continue; // Пропускаем чётные
    echo(i);
}
// Вывод: 1 3 5 7 9
```

### 15.4 Бесконечные циклы

**Новое в версии 1.4.** С настройкой `max_iteration = -1`:

```
@VoidApp "InfiniteLoop";
@VoidSetting max_iteration = -1;

main()
{
    create:int i = 0;
    while (true)
    {
        echo("Итерация:", i);
        i++;
        if (i >= 10) break; // Выход по условию
    }
}

@VoidEnd;
```

### 15.5 Защита от бесконечных циклов

По умолчанию интерпретатор имеет **лимит в 1 000 000 итераций**. Если цикл превысит этот лимит, программа остановится с ошибкой:

```
[Runtime Error] Превышен лимит итераций (1000000).
```

> ⚠️ **Важно:** `break` и `continue` работают только внутри циклов (`while`, `for`).

# 16. Ссылки и разыменование

### 16.1 Создание ссылки — `&`

Оператор `&` создаёт ссылку на переменную:

```
create:int a = 10;
create:link ptr = &a;
```

### 16.2 Разыменование — `*`

Оператор `*` получает значение по ссылке:

```
create:int a = 10;
create:link ptr = &a;

echo(*ptr);    // 10
*ptr = 20;     // a теперь 20
echo(a);       // 20
```

### 16.3 Ссылки на элементы массивов

**Новое в версии 1.4.** Можно создавать ссылки на конкретные элементы массива:

```
create:list arr = [10, 20, 30];
create:link first = &arr[0];

echo(*first);  // 10
*first = 100;  // arr[0] теперь 100
echo(arr);     // [100, 20, 30]
```

### 16.4 Разыменование с доступом по индексу

**Новое в версии 1.4.** Оператор `*` работает с index access:

```
create:list arr = [1, 2, 3, 4, 5];
create:link arrPtr = &arr;

(*arrPtr)[0] = 100;
echo(arr);  // [100, 2, 3, 4, 5]
```

### 16.5 Пример — обмен значений через ссылки

```
@VoidApp "SwapExample";

@VoidFunction create:void swap(create:link a, create:link b) {
    create:int temp = *a;
    *a = *b;
    *b = temp;
}

main()
{
    create:int x = 10;
    create:int y = 20;
    echo("До обмена: x =", x, "y =", y);
    swap(&x, &y);
    echo("После обмена: x =", x, "y =", y);
}

@VoidEnd;
```

**Вывод:**

```
До обмена: x = 10 y = 20
После обмена: x = 20 y = 10
```

# 18. Приведение типов

### 18.1 Автоматическое приведение

При создании переменной значение **автоматически приводится** к указанному типу:

```
create:int x = 3.7;        // x = 3 (floor)
create:float y = 42;       // y = 42.0
create:string z = 100;     // z = "100"
create:bool flag = 1;      // flag = true
```

> ⚠️ Для типов `list` и `dict` автоматическое приведение **не выполняется** — значение должно быть соответствующего типа.

### 18.2 Явное приведение

Используйте функции преобразования:

```
create:string numStr = "42";

create:int num = toInt(numStr);         // 42
create:float dec = toFloat(numStr);     // 42.0
create:bool b = toBool(numStr);         // true
create:string s = toString(42);         // "42"
```

### 18.3 Правила конкатенации

Если один из операндов `+` — строка, результат — **строка**:

```
echo("Результат: " + 42);           // "Результат: 42"
echo(42 + " - ответ");              // "42 - ответ"
```

Если оба операнда — числа, результат — **число**:

```
echo(10 + 20);                      // 30
echo(3.14 + 2.86);                  // 6.0
```

Если оба операнда — списки, результат — **новый список**:

```
echo([1, 2] + [3, 4]);              // [1, 2, 3, 4]
```

### 18.4 Приведение для var и void

Для типов `var` и `void` приведение выполняется **автоматически** из значения:

```
create:var x = 42;      // Тип: int
create:var y = "hello"; // Тип: string

x = "text";             // Тип меняется на string
```

# 21. Ошибки и отладка

### 21.1 Типы ошибок

#### Ошибки лексера `[Lexer Error]`

```
[Lexer Error] Неожиданный символ: '$' (строка 5, столбец 10)
[Lexer Error] Незакрытая строка (строка 3, столбец 1)
[Lexer Error] Незакрытый многострочный комментарий
[Lexer Error] Неизвестная директива: @VoidStart
```

#### Ошибки парсера `[Parser Error]`

```
[Parser Error] Ожидался токен SEMICOLON, получен RBRACE (строка 7, столбец 1)
[Parser Error] Программа должна начинаться с @VoidApp или @VoidLibs
[Parser Error] Неожиданная инструкция: 'xyz'
[Parser Error] Ожидался тип переменной (string/int/float/bool/list/dict/var/void/link)
```

#### Ошибки выполнения `[Runtime Error]`

```
[Runtime Error] Переменная 'x' не определена
[Runtime Error] Переменная 'x' уже определена
[Runtime Error] Деление на ноль
[Runtime Error] Невозможно преобразовать 'abc' в число
[Runtime Error] Неизвестная функция: 'myFunc'
[Runtime Error] Функция 'sqrt' ожидает 1 аргумент(ов), получено 2
[Runtime Error] Превышен лимит итераций (1000000)
[Runtime Error] Индекс 5 выходит за границы списка (длина: 3)
[Runtime Error] Ключ 'xyz' не найден в словаре
```

### 21.2 Частые ошибки и решения

| Ошибка | Причина | Решение |
|---|---|---|
| Забыта `;` | `create:int x = 5` | `create:int x = 5;` |
| Забыт `@VoidEnd;` | Программа не завершена | Добавьте `@VoidEnd;` |
| `create:` без типа | `create: x = 5;` | `create:int x = 5;` |
| Переменная не создана | `echo(x);` без `create:` | Сначала `create:int x = 0;` |
| Двойное создание | `create:int x = 1;` дважды | Используйте `x = 2;` для изменения |
| Индекс вне диапазона | `items[10]` при длине 3 | Проверьте `length(items)` |
| Библиотека без @VoidLibs | Файл начинается с @VoidApp | Используйте `@VoidLibs` |
| Вызов без namespace | `add(1, 2)` | `math::add(1, 2)` |

### 21.3 Советы по отладке

1. **Используйте `echo()` для отладки:**

```
echo("DEBUG x =", x);
echo("DEBUG type:", typeof(x));
```

2. **Проверяйте длину перед доступом по индексу:**

```
create:list items = [1, 2, 3];
create:int idx = toInt(write("Индекс: "));
if (idx >= 0 && idx < length(items))
{
    echo("Элемент:", items[idx]);
}
else
{
    echo("Индекс вне диапазона!");
}
```

3. **Используйте `break` для выхода из проблемных циклов:**

```
create:int i = 0;
while (i < 1000)
{
    echo("Итерация:", i);
    if (i > 10) break; // Защита от бесконечного цикла
    i++;
}
```
