# Changelog

## [1.4] — 23.07.2026

### Добавлено
- **@VoidSetting** — директива конфигурации интерпретатора. Поддерживаемые настройки: `max_iteration` (лимит итераций циклов, `-1` = бесконечно), `automatic_type` (автоматический вывод типа для `var`).
- **@VoidLibs** — директива для создания библиотек. Файлы с `@VoidLibs` помечаются как библиотеки и не выполняются напрямую.
- **namespace** — пространства имён для организации функций библиотек. Вызов функции: `namespace::function(args)`.
- **fn** — компактный синтаксис объявления функций с указанием возвращаемого типа через `->`. Пример: `fn add(int a, int b) -> int { return a + b; }`.
- **var** — динамический тип, выводящий тип из значения инициализатора. Позволяет менять тип при повторном присваивании.
- **break** — выход из цикла (`while`, `for`).
- **continue** — переход к следующей итерации цикла.
- **Ссылки на элементы массивов** — возможность создавать ссылки на конкретные элементы массива: `create:link ref = &arr[0];`.
- **Расширенный разыменование** — оператор `*` теперь работает с доступом по индексу и ссылками на элементы массивов: `(*arr)[i]`.
- **Web playground** — интерпретатор в браузере (`web/index.html`). Lexer, Parser и Interpreter портированы в JavaScript. Ввод через `window.prompt()`.
- **void как тип переменной** — переменные типа `void` могут быть неинициализированы (значение по умолчанию: `null`). Позволяет менять тип при присваивании.
- **Импорт библиотек** — директива `@VoidImport "путь/к/файлу.void"` для подключения библиотек.

### Изменено
- **Parser** — расширен AST: добавлены `VoidSettingNode`, `NamespaceCallNode`, `CreateNamespaceNode`, `ArrayElementRefNode`. `ProgramNode` теперь содержит поля `isLib`, `namespace`, `config`, `settings`.
- **Interpreter** — добавлены `BreakSignal`, `ContinueSignal`, `registerLibrary()`, `executeNamespaceCall()`, `inferType()`. `Environment` получил метод `setType()`. `DereferenceNode.target` теперь `ASTNode` (вместо `string`).
- **Lexer** — добавлены токены: `VOID_SETTING`, `VAR`, `BREAK`, `CONTINUE`, `FN`, `ARROW`, `VOID_LIBS`, `NAMESPACE`, `NAMESPACE_SEP`, `TYPE_VAR`. Добавлены директивы: `@VoidSetting`, `@VoidLibs`. Добавлены двухсимвольные операторы: `->`, `::`.

## [1.2] — 27.05.2026

### Добавлено
- **Функции пользователя** — возможность объявлять и вызывать собственные функции через `@VoidFunction`.
- **Ссылки на переменные** — поддержка работы со ссылками на переменные.
- **Инкремент и декремент** — добавлены операторы `++` и `--` для удобного изменения значений переменных.
- **Составное присваивание** — добавлены операторы `+=`, `-=`, `*=`, `/=`, `%=` для упрощения арифметических операций с присваиванием.

## [1.1.1] — 19.02.2026

### Добавлено
- **Объявление нескольких переменных одного типа в 1 create**: можно объявить несколько переменных одного типа.
- **Объявление переменных без значений**: можно объявить переменную без значения, и в последствии присвоить значение.
