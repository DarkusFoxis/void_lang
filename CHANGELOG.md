# Changelog

## [1.2] — 27.05.2026

### Добавлено
- **Функции пользователя** — возможность объявлять и вызывать собственные функции через `function`.
- **Ссылки на переменные** — поддержка работы со ссылками на переменные.
- **Инкремент и декремент** — добавлены операторы `++` и `--` для увобного изменения значений переменных.
- **Составное присваивание** — добавлены операторы `+=`, `-=`, `*=`, `/=`, `%=` для упрощения арифметических операций с присваиванием.

## [1.1.1] — 19.02.2026

### Добавлено
- **Объявление нескольких переменных одного типа в 1 create**: можно объявить несколько переменных одного типа.
- **Объявление переменных без значений**: можно объявить переменную без значения, и в последствии присвоить значение.
